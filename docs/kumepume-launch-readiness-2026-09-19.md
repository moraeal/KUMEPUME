## 결론

기존 홈페이지 콘텐츠 이전과 보존은 완료됐다. 현재 미리보기에는 검증되지 않은 주소·전화·이메일·후원계좌·현행 임원명단이 현재 정보처럼 노출되지 않는다. 빌드 또는 콘텐츠 이전 오류는 없으며, 공식 공개를 막는 항목은 **현행 정보 확정 3건과 운영 전환 설정**이다.

## 실제 배포 화면 점검

- 메인, 단체 소개, 사업, 활동과 성과, 과거 기록, 영상 기록, 투명경영, 함께하기, 오시는 길의 직접 주소 접속을 확인했다.
- 점검한 모든 페이지에서 가로 넘침과 실제 이미지 로딩 오류는 0건이었다.
- 화면 아래 이미지는 지연 로딩되며, 로딩 완료 후 원본 표시를 재확인했다.
- 미리보기 배너와 검색 차단 메타정보가 실제 배포 화면에도 적용돼 있다.

## 대표님이 확정해 주실 정보

아래 자료가 도착하면 현재 정보 페이지와 후원·문의 기능을 한 번에 완성할 수 있다.

1. 최신 법인 등기 또는 사업자·고유번호증에 적힌 공식 소재지
2. 공개할 대표전화, 공식 이메일, 방문 가능 시간
3. 현행 대표자·이사·감사 명단과 공개 가능한 직함·약력
4. 후원 계좌의 은행명·예금주·계좌번호와 정기후원 CMS 운영 방식
5. 문의·후원 신청 시 사용할 개인정보 수집·이용 동의문과 실제 수신 담당자
6. 최신 정관, 최근 사업계획·사업보고·결산서류 및 2015년 결산 공고 첨부 원본

## 공개 전 실행 순서

1. 현행 정보와 증빙을 대조해 소개·조직·오시는 길·투명경영 페이지를 갱신한다.
2. 후원·문의 접수 방식을 연결하고 개인정보 동의, 오류·스팸 대응, 수신 확인을 시험한다.
3. 데스크톱·모바일에서 메뉴, 24개 활동 상세, 12개 과거 기록, 8개 PDF를 최종 점검한다.
4. `kumepume.org` 연결 직전에 운영 빌드로 전환하고 미리보기 안내를 제거한다.
5. 도메인과 HTTPS가 정상 작동한 뒤 `noindex`와 `robots.txt` 차단을 해제하고 사이트맵을 제출한다.

## 자동 점검

다음 명령으로 콘텐츠 보존, 민감한 현행 정보 비공개, 후원 기능 잠금, 검색 차단과 도메인 준비 상태를 다시 확인한다.

```bash
pnpm run audit:launch
```

현재 기준은 오류 0건이며, 공개 전 차단 항목은 현행 정보·검색 전환·운영 단계·도메인 연결이다.
